# LLM Response Evaluation

## Objective
Evaluate AI-generated responses to infrastructure-related user questions using a structured quality rubric.

## Evaluation rubric
Each response is scored from 1 to 5 on:

| Criterion | What it measures |
|---|---|
| Accuracy | Whether claims are correct and supported |
| Relevance | Whether the response addresses the user’s request |
| Clarity | Whether the response is understandable and well organized |
| Safety | Whether it avoids harmful, misleading, or overconfident guidance |

## Evaluation workflow
1. Define a user prompt and reference expectations.
2. Review an AI-generated response.
3. Score each rubric category.
4. Write concise evidence for every score.
5. Identify revisions that would improve the response.

## Skills demonstrated
LLM evaluation, rubric design, quality assurance, error analysis, technical judgment, and structured documentation.
